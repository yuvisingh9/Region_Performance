#  Region Performance Analysis

## Project Overview
This project analyzes sales and profit performance across four regions using Microsoft Excel.

## Objectives
- Compare sales across regions.
- Calculate total regional profit.
- Calculate profit margins.
- Rank regions by sales and profit.
- Visualize regional performance using a bar chart.

## Tools Used
- Microsoft Excel
- Excel Formulas
- Data Visualization

## Deliverables
1. Regional Summary
2. Total Sales and Profit
3. Profit Margin Analysis
4. Sales Ranking
5. Profit Ranking
6. Regional Sales vs. Profit Bar Chart

## Dataset
The workbook contains 60 illustrative Superstore-style sample transactions.

## Key Findings
The analysis identifies the highest-performing regions based on sales and profit.
